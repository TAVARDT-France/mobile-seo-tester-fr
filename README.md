# Testeur de SEO Mobile et Ergonomie Smartphone

Audit technique de la balise meta viewport, du responsive design et des cibles tactiles selon Google Mobile-First.

***

## Capacites d Audit de SEO Mobile

* **Validation de la Balise Viewport**: Verification de la configuration `width=device-width, initial-scale=1` et controle de l accessibilite tactile.
* **Detection des Debordements de Contenu**: Identification des largeurs fixes provoquant un defilement horizontal sur smartphone.
* **Ergonomie des Cibles Tactiles**: Mesure de l espacement et des dimensions minimales des boutons et hyperliens tactiles.
* **Lisibilite Typographique**: Controle de la taille des polices sans necessite d intervention de zoom par l utilisateur.
* **Score de Conformite Mobile-First**: Note technique sur 100 avec priorisation des corrections requises par Google.

***

## Installation et Utilisation

Fonctionne avec Python 3.8 ou superieur sans bibliotheque externe.

```bash
git clone https://github.com/TAVARDT-France/mobile-seo-tester-fr.git
cd mobile-seo-tester-fr
python mobile_seo_tester.py https://entreprise.fr
```

Sortie detaillee au format JSON:

```bash
python mobile_seo_tester.py https://entreprise.fr -json
```
